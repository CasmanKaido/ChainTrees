# 🌳 ChainTrees

**Plant Trees, Earn Tokens, Save the Planet.**

ChainTrees is a Web3 environmental impact platform that gamifies reforestation. Users can mint digital trees (NFTs) that correspond to real-world impact, earn tokens through staking and educational quizzes, and participate in DAO governance.

## 🚀 Features

-   **🌱 Minting Engine**: Mint unique, procedurally generated tree NFTs.
-   **💧 Interactive Forest**: Water and care for your trees to boost growth.
-   **📊 Impact Dashboard**: Track your carbon offset and environmental contribution.
-   **🏆 Leaderboard**: Compete with other foresters for top rankings.
-   **🎖️ Achievements**: Unlock badges for milestones and rare collections.
-   **💰 Staking**: Stake your trees to earn TREE tokens.
-   **🏪 Marketplace**: Buy and sell trees with other players.
-   **🗳️ Governance**: Vote on project proposals and future developments.
-   **📚 Learn to Earn**: Take quizzes on sustainability to earn rewards.
-   **📱 Mobile Ready**: Fully responsive PWA design for any device.

## 🛠️ Tech Stack

-   **Frontend**: Vanilla JS, Vite, Chart.js
-   **Web3**: Reown AppKit, Wagmi, Viem
-   **Smart Contracts**: Solidity, Hardhat (Base Network)
-   **Styling**: CSS Variables, Glassmorphism
-   **Testing**: Vitest

## 📦 Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/chaintrees.git
    cd chaintrees
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Set up environment variables**
    Copy `.env.example` to `.env` and fill in your keys:
    ```bash
    cp .env.example .env
    ```

4.  **Run local server**
    ```bash
    npm run dev
    ```

## 🧪 Testing

Run the comprehensive test suite:
```bash
npm test
```
