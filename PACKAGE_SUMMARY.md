## 🚀 Quick Start Guide

### Step 1: Install Bun
```powershell
# Run in PowerShell (Administrator)
irm bun.sh/install.ps1 | iex

# Verify installation
bun --version
```

### Step 2: Read the Documentation
1. Start with **GETTING_STARTED.md** - Understand prerequisites
2. Review **README.md** - Get project overview
3. Open **COMMIT_CHECKLIST.md** - Your implementation guide

### Step 3: Get Your API Keys
1. **WalletConnect Project ID**: https://cloud.reown.com
2. **Infura/Alchemy Key**: For RPC endpoints
3. **Pinata API Key**: For IPFS storage (needed later)

### Step 4: Initialize Project
```powershell
# Navigate to project directory
cd c:\Users\XPS\Desktop\New_folder\PJS\rest

# Initialize Git
git init
git remote add origin https://github.com/CasmanKaido/ChainTrees.git

# Start with Commit 1
# Follow COMMIT_CHECKLIST.md
```
